Notes
-----
- DecodeScalars 0 allocs: internal arena eliminates all container allocation
  on the default path. Values valid until next Decode() on same decoder.
- DecodeNestedMapStrict 10 allocs: string allocations for map keys (not
  arena-managed). Could reach 0 with ZeroCopy+Arena but that requires
  caller to understand source-buffer lifetime.
- WriteValue fast-path: scalar kinds dispatch directly to wire.AppendHead
  or single-byte writes, bypassing Encode entirely.
- Remaining map allocs come from string(src[start:end]) in text decode.
  These are fundamental to Go's string immutability guarantee unless
  ZeroCopy is enabled.
